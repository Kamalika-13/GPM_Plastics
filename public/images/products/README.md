# Product image assets

Replace the product images by copying your own files into this folder using these exact names:

- `ball-cup.png`
- `mango-cup.png`
- `strawberry-cup.png`
- `matka-cup.png`
- `custom-cup.png`
- `curd-cup.png`
- `ice-cream-spoon.png`
- `wooden-spoon.png`

Use landscape images around 4:3. The built-in illustration appears until an image file is present, and also remains the fallback if an image cannot load. Product image paths are configured in `src/products.js`.
